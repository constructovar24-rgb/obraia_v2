# PRODUCT.md

## Objetivo del ERP
OBRA IA v3 es una aplicación de gestión orientada a empresas de obra, diseñada para centralizar expedientes, clientes, presupuestos y procesos operativos en una herramienta sencilla y escalable.

## Flujo funcional principal
1. Crear y gestionar expedientes.
2. Registrar clientes y asociarlos a proyectos.
3. Generar presupuestos de obras y partidas.
4. Consultar información de seguimiento desde pantallas especializadas.
5. Preparar la base para futuras integraciones con IA y documentos.

## Módulos existentes y previstos
### Módulos existentes
- Expedientes
- Clientes
- Presupuestos de piscinas

### Módulos previstos
- Obras
- Contactos
- Base de precios
- Facturas y costes
- Documentación y fotografías
- Integración con IA
